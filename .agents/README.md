# Pracovní skills Mystické Hvězdy

Začni konkrétním zadáním a [společným produktovým kontextem](product-marketing-context.md). Pravidla projektu jsou v [AGENTS.md](../AGENTS.md). Tato knihovna obsahuje i obecné marketingové a SEO návody; nejsou všechny potřeba pro každou úlohu.

| Úloha | Hlavní skill |
|---|---|
| Zjednodušení nabídky a cesty k nákupu | [page-cro](skills/page-cro/SKILL.md) |
| Vzhled, mobil, přístupnost | [web-design-guidelines](skills/web-design-guidelines/SKILL.md) |
| Ověření změněného formuláře, CTA, checkoutu | [conversion-qa](skills/conversion-qa/SKILL.md) |
| Výpočet, losování, prompt, kvalita výkladu | [astro-engine-regression](skills/astro-engine-regression/SKILL.md) |
| Reference, sliby a důvěryhodnost | [trust-audit](skills/trust-audit/SKILL.md) |
| Události, objednávky a vyhodnocení | [analytics-tracking](skills/analytics-tracking/SKILL.md) |
| Produkční stav nebo autorizované nasazení | [railway-deploy-guard](skills/railway-deploy-guard/SKILL.md) |
| Zápis nového produktového rozhodnutí | [product-marketing-context](skills/product-marketing-context/SKILL.md) |

Další skill načti pouze pro skutečně potřebnou specializaci. Obecné katalogy, historické workflow šablony a experimenty v referencích jsou volitelné podklady; neurčují povinný počet auditů, variant, kapitol ani testů.

Při údržbě upravuj projektové kopie v `.agents/skills`, nikoliv sdílenou cache pluginů. Zachovej užitečné reference a autorství. Aktuální rozhodnutí patří do produktového kontextu, implementační podrobnosti do odpovídajícího dokumentu v `docs/`. Do každého skillu nekopíruj celý kontext.
