# W01 — společná navigace

Zdrojová realizace, závěrečné UI ověření čeká. Homepage a `components/header.html` mají shodné skupiny Astrologie, Tarot a věštění, Čísla a energie, Poznání, Výklady a služby. Původní cílové URL a nástroje zůstávají dostupné.

Dropdowny používají skutečné buttony s `aria-expanded` a `aria-controls`. Obě existující inicializační větve sdílejí ochranu `data-nav-initialized`; přidávají click, nativní Enter/Space, šipku dolů na první odkaz, Escape s návratem fokusu, zavření při odchodu fokusu a kliknutí mimo. Starší otevřené anchor varianty nadále ruší navigaci na `#` a podporují Space. Zavřené mobilní menu je `inert`, ne jen vizuálně mimo obraz.

Desktopové CSS zobrazuje inicializované menu podle stejné `.is-active`, kterou udržuje JS a ARIA; myš nastavuje stejný stav jako klávesnice. Hover bez inicializace zůstává jako záložní chování. Resize nezanechá otevřenou mobilní variantu na desktopu. Širší přesun informační architektury a hromadné rušení odkazů se nedělal.

Připravit do jedné závěrečné kontroly: obě větve init, myš/Tab/Enter/Space/šipka/Escape, 390/320 px, resize, host a přihlášený účet, odchod na existující cíl, starší otevřené HTML. Tento dokument neprohlašuje runtime za ověřený. Po zdrojích je nutný build JS a tří používaných základních CSS balíků.
