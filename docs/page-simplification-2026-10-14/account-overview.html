A05 · P1 · Produkce bez tokenu; lokální syntetický vypršelý fragment

Neplatný vstup do resetu nemá jasný recovery stav

/prihlaseni.html?reset=true bez tokenu ukáže běžný login bez informace o obnově. Lokální reset=true#error=access_denied&error_code=otp_expired ukázal formulář nového hesla; po vyčištění URL zůstal formulář otevřený. Nebyl zadán ani změněn nový password.

Navržená oprava: Rozlišit platný recovery vstup, chybějící token a provider error před zobrazením polí. Neplatný odkaz musí nabídnout vyžádání nového odkazu. Skutečný platný e-mailový reset se musí ověřit zvlášť.

A06 · P2 · Lokální simulace nedostupného API

Při odpovědi API mimo JSON se zákazníkovi ukáže technická chyba

Smyšlené přihlášení audit@example.invalid proti statickému lokálnímu serveru zobrazilo anglický JSON parse error: Unexpected token < … is not valid JSON. Toto není důkaz výpadku produkce.

Navržená oprava: Ošetřit neočekávaný formát/HTTP odpověď; zobrazit srozumitelnou českou chybu a ponechat možnost zopakovat. Technický detail logovat zvlášť, bez hesel/tokenů.

A07 · P2 · Zdroj; aktivní modal nebyl v této kontrole vyvolán

Starší auth modal má slabší přístupnost než samostatná stránka

Close je span bez keyboard role/tabindex, labely nejsou svázané s poli, obal nemá dialog/aria-modal. Auth-copy-fixes dodává close aria-label, nikoli keyboard button. Auth-client otevření nemá vlastní fokus/Escape management.

Navržená oprava: Buď sjednotit aktivní vstupy na samostatnou stránku, nebo doplnit skutečný dialog s tlačítkem zavření, názvy polí, fokusovým cyklem a návratem fokusu. Nejprve určit, které vstupy legacy modal používají.
